# AI Telegram Assistant для Центр Красок #1

Telegram-бот с AI-ассистентом, который отвечает на вопросы пользователей о компании «Центр Красок #1» на основе заранее собранной и структурированной базы знаний.

Бот работает в формате обычного чата: пользователь пишет обычное сообщение, а бот отвечает без команд и меню.

## Цель проекта

Проект выполнен как тестовое задание для демонстрации навыков:

- работы с AI API;
- интеграции внешних API;
- разработки простого backend-сервиса;
- создания Telegram-бота;
- структурирования информации из открытых источников;
- ограничения ответов AI на основе базы знаний.

## Возможности

- ответы на вопросы о компании;
- обычный чат без команд и меню;
- ответы на основе подготовленной базы знаний;
- защита от выдуманных фактов;
- обработка вопросов, на которые нет данных;
- контекст последних сообщений пользователя;
- интеграция с Gemini API;
- Telegram Bot API;
- Express health-check для деплоя.

## Примеры вопросов

Пользователь может спросить:

- Чем занимается компания?
- Какие услуги предоставляет?
- Где находится офис?
- Какие бренды представлены?
- Какие товары продаёт компания?
- Какие технологии используются?
- Какие есть вакансии?
- Кто клиенты компании?
- Что разрабатывает компания?
- Как связаться с компанией?

## Защита от галлюцинаций

AI-ассистент получает заранее подготовленную базу знаний о компании и системные правила.

Если информации нет в базе знаний, бот отвечает:

> В открытых данных компании такой информации нет.

Если вопрос не связан с компанией, бот отвечает:

> Я могу отвечать только на вопросы, связанные с компанией Центр Красок #1, её товарами, услугами, контактами и открытой информацией.

Бот не выдумывает:

- цены;
- актуальные вакансии;
- клиентов;
- владельцев;
- зарплаты;
- внутренние технологии;
- сотрудников;
- финансовые данные.

1. Клонировать репозиторий
git clone https://github.com/username/ai-telegram-company-assistant.git
cd ai-telegram-company-assistant
2. Установить зависимости
npm install
3. Создать .env файл

Создайте файл .env в корне проекта:

BOT_TOKEN=your_telegram_bot_token
GEMINI_API_KEY=your_gemini_api_key

Для разработки:

npm run dev

Для production-запуска:

npm start

После запуска в терминале должно появиться:

Server is running on port 3000
Health-check
